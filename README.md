# Голос

PWA для айфона: план развития вокала на 12 недель, тренажёр с определением высоты звука и учитель на Claude.

## Что умеет

- **Диагностика**: диапазон, попадание в ноты, длительность звука. Ноты всех упражнений подбираются под диапазон.
- **Ежедневное занятие** на 12–18 минут, с песней около 20: дыхание, разогрев, интонация, слух, песня, заминка. Время считается из настоящей длительности упражнений.
- **Тренажёр**: линия голоса рядом с целевой нотой, отсчёт перед вступлением, оценка в центах с поправкой на опоздание, разбор по нотам попевки и совет сразу после упражнения.
- **Песни**: текст с аккордами, транспонирование, запись мелодии с инструмента, разучивание фраз, исполнение целиком с оценкой или под свой аккомпанемент.
- **Учитель Claude**: разбор занятия, недельный разбор с корректировкой плана, чат. Учитель ведёт заметки об ученике и видит свои прошлые разборы.
- **Прогресс**: графики и журнал. Работает без сети (кроме учителя), данные хранятся на устройстве.

Звук никуда не отправляется. Учитель получает только измерения и заметки, сам голос он не слышит.

## Запуск

Сборка не нужна: это статический сайт.

```bash
python3 -m http.server 8080
```

Микрофон в браузере работает только по HTTPS или на `localhost`.

### GitHub Pages

1. В репозитории откройте Settings → Pages.
2. В разделе Build and deployment выберите Deploy from a branch, укажите ветку и папку `/ (root)`.
3. Откройте выданный адрес в Safari на айфоне и добавьте сайт на экран «Домой».

### Учитель

В настройках приложения введите ключ API Anthropic. Ключ хранится только в браузере устройства, запросы идут напрямую в API.

## Устройство

| Путь | Назначение |
|---|---|
| `js/pitch.js` | определение высоты (YIN), разбор звука на ноты |
| `js/scoring.js` | оценка попадания, поправка на опоздание |
| `js/timeline.js` | расписание упражнений и расчёт их длительности |
| `js/tips.js` | советы по результату упражнения |
| `js/curriculum.js` | упражнения, план, подгонка под диапазон |
| `js/runner.js` | тренажёр: проведение упражнений всех типов |
| `js/songparse.js` | разбор текста с аккордами |
| `js/claude.js` | запросы к Claude API |
| `js/views/` | экраны |
| `vendor/anthropic-sdk.js` | официальный SDK `@anthropic-ai/sdk`, собранный в один файл |
| `sw.js` | офлайн-режим |

При добавлении нового файла приложения впишите его в список `SHELL` в `sw.js`, иначе он не попадёт в офлайн-кэш.

### Обновление SDK

```bash
npm install @anthropic-ai/sdk esbuild
printf "import Anthropic from '@anthropic-ai/sdk';\nimport { jsonSchemaOutputFormat } from '@anthropic-ai/sdk/helpers/json-schema';\nexport { Anthropic, jsonSchemaOutputFormat };\nexport default Anthropic;\n" > entry.mjs
npx esbuild entry.mjs --bundle --format=esm --platform=browser --target=safari15 --minify --outfile=vendor/anthropic-sdk.js
```

## Тесты

```bash
npm test
```

Проверяются определение высоты, разбор на ноты, оценка и поправка на опоздание, длительность занятий, советы, рост диапазона, аккорды и разбор песен.
